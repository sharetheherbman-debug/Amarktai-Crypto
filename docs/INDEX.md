## 🔍 Supported Exchanges

The platform supports exactly **7 exchanges**:

1. **Luno** - Max 5 bots per user
2. **Binance** - Max 10 bots per user
3. **KuCoin** - Max 10 bots per user
4. **Bybit** - Max 10 bots per user
5. **Kraken** - Max 10 bots per user
6. **Bitget** - Max 10 bots per user
7. **Gate.io** - Max 10 bots per user

> **Note**: VALR, OVEX, and Emergent are **not supported**.
