# Frontend Screenshot Checklist

Use this quick checklist when capturing UI screenshots for review.

## Setup
1. `cd frontend`
2. `npm start`
3. Open `http://localhost:3000/dashboard` and log in.

## Screenshots to capture
- **Overview**: show the 50/50 split, dark image overlay, and the scrollable info pane.
- **AI Chat**: show the full-height chat with pinned input, message scroll, and the “Sending…” indicator.
- **API Setup**: capture the grid of API cards, one expanded card with inputs, and status badges.
- **Countdown**: capture the Road to R1,000,000 header, milestones, and progress visuals.
- **System Mode**: show the “Reset Paper Session” card with the password prompt text.
- **Admin**: capture the uniform cards and user management table (if admin access is enabled).
